# BananiUI Attribution and Modification Notice

BananiUI is a modified distribution based on the Rayfield Interface Suite by SiriusSoftwareLtd and its original contributors.

## Modifications in this distribution

- Removed the startup splash screen.
- Removed analytics, telemetry, reporter downloads, and heartbeat requests.
- Removed the remote safety-prompt and Discord-boost helper downloads.
- Added success, error, warning, and information notification helpers.
- Added `SafeCall` for user-visible callback error reporting.
- Added a successful-load notification showing the script/window name and current game name.
- Renamed public-facing library references to BananiUI where practical.
